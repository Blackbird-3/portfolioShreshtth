## 🛠 set-up

1. Install the dependencies

   ```sh
   npm install
   ```

2. Start the development server

   ```sh
   npm run dev
   ```

## 🚀 build and run for production

1. Generate the production build

   ```sh
   npm run build
   ```

2. Start it

   ```sh
   npm start
   ```
